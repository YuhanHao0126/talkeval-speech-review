# TalkEval++

案例库仅保留新版交付包中的团队演示《人生，像一场泊松过程》，此前10个旧案例已从网站移除。

2026-11-18 更新版：双通道演讲提词器、动作残影、观点证据核对、PPT内容跟随及录屏布局。

网站：https://yuhanhao0126.github.io/talkeval-speech-review/

- `docs/`：GitHub Pages 发布目录。`dist/`同步相同版本。
- `server/`：11月18日完整交付包中的Python源码与测试。运行需要原交付包内的模型、数据、static和original-site资源，具体见其中的运行说明。
- `docs/demo/`：团队提供的演示录像、时间字幕和原模型预计算输出。观察2秒、预测2秒、每0.2秒一帧；无未来观测泄露。

网页版提供案例演示，没有连接Python后端。实时动作推理、录像上传/跨设备保存和PPTX转图片需要运行完整本机项目。声音独立收益和增强显示精度的结论沿用原项目边界，见网站的“网页版说明”。

发布沿用 main 分支的 docs 目录，无须新增服务。预测导出来源、文件指纹和版本号在 `docs/release.json`。
